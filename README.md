# Portfolio

A personal portfolio website built with React and Vite.

## Getting started

### Install dependencies

```bash
npm install
```

### Run locally

```bash
npm run dev
```

Then open the local URL shown in the terminal (usually `http://localhost:5173`).

### Build for production

```bash
npm run build
```

The production files will be in the `dist` folder. Preview the build with:

```bash
npm run preview
```
